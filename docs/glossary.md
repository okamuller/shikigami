# 用語集 — 式神鑑定

## 占術

| 用語 | 意味 |
|---|---|
| 六壬神課（りくじんしんか） | 中国・日本で発達した占術。式神（十二天将）を盤上に配置して占う |
| 十二天将 | 貴人 / 騰蛇 / 朱雀 / 六合 / 勾陳 / 青龍 / 天空 / 白虎 / 太常 / 玄武 / 太陰 / 天后 |
| 五行 | 木・火・土・金・水 |
| 観相学 | 顔や手の相から運命・性格を読み解く学問。江戸の水野南北が大成 |
| 節食開運 | 食を慎むことで運を開くという南北の中心思想 |
| 命式（めいしき） | 生年月日から導かれた占い盤の構成 |
| 月将（げっしょう） | 月ごとに割り当てられる神。六壬の盤面要素のひとつ |

## 技術

| 用語 | 意味 |
|---|---|
| Supabase | Auth + Postgres + Edge Functions の BaaS |
| Edge Function | Supabase が提供する Deno ベースのサーバレス関数 |
| RLS (Row Level Security) | Postgres の行レベル権限制御。`auth.uid() = user_id` 等で書く |
| Prompt Caching | Anthropic API のシステムプロンプトキャッシュ機能。入力トークン費用を約 90% 削減 |
| Vision Framework | Apple のオンデバイス画像解析フレームワーク |
| Conventional Commits | `feat:` `fix:` 等の prefix で意図を表すコミット規約 |
| Phased Release | App Store の段階的リリース機能（10% → 100%） |

## 法務

| 用語 | 意味 |
|---|---|
| 景表法 | 景品表示法。「必ず当たる」等の断定的表現を規制 |
| 特商法 | 特定商取引法。事業者表記・解約方法・自動更新条件の明示を要求 |
| 薬機法 | 医薬品医療機器等法。健康効能効果の謳いを規制 |
