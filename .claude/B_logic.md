### 計算ロジック（JavaScript）

```js
function calcMeishiki(birthDate) {
  const d = new Date(birthDate);
  const year = d.getFullYear();
  const month = d.getMonth() + 1;
  const day = d.getDate();

  // 干支（60年サイクル）
  const kanIdx = ((year - 4) % 10 + 10) % 10;  // 十干
  const shiIdx = ((year - 4) % 12 + 12) % 12;  // 十二支

  // 式神 = (月 + 日 - 2) mod 12
  const shikigamiIdx = ((month + day - 2) % 12 + 12) % 12;

  // 五行マップ（十干→五行）
  const gogyoMap = ["木","木","火","火","土","土","金","金","水","水"];
  const gogyo = gogyoMap[kanIdx];

  // 運気スコア（0〜100）
  const score = ((year * 7 + month * 31 + day * 13) % 40) + 60;

  return { kan, shi, shikigami, getsusho, gogyo, score };
}
```

### 実装難易度

スライダー入力で疑似的に観相を再現。カメラ風UIで体験を演出。

Apple Vision Frameworkで顔68点のランドマーク検出  
→ 各パーツの比率をスコア化（0〜100）  
→ テンプレ選択 → Claude API江戸口調変換

## ENGINE C: Claude API統合

### システムプロンプト（晴明）

```
あなたは平安時代の陰陽師・安倍晴明です。
- 文語体（〜なり、〜べし、〜おろう、汝、式神）を使う
- 神秘的で詩的な表現を心がける
- 200文字以内で完結に
- 段落2つ：運命の告知 / 行動の教え
```

### システムプロンプト（南北）

```
あなたは江戸後期の観相家・水野南北です。
- 江戸の口語体（〜じゃ、〜なるぞ、〜であろう）を使う
- 人相・食・節制の教えを織り込む
- 厳しくも温かみのある口調
- 200文字以内で完結に
```
