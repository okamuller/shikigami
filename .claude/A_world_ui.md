# A. 世界観・UIコンセプト — 式神鑑定

## アプリ名
**式神鑑定 / SHIKIGAMI FORTUNE**

## コンセプト
平安時代の陰陽師・安倍晴明と江戸の観相家・水野南北をAIで蘇らせた、
日本初の「歴史上の賢者AI占いアプリ」。

> 「運命を知る（晴明）× 運命を変える（南北）」

---

## アプリ名候補

| 案 | 読み | 方向性 |
|---|---|---|
| **式神鑑定** | しきがみかんてい | 晴明色・若年層向け ← **採用** |
| 陰陽秘伝 | おんみょうひでん | 本格・神秘感最強 |
| 千年の占者 | せんねんのうらなえ | 詩的・幅広い層 |

## タイポグラフィ

- Display: **源ノ明朝 / Yu Mincho**
- Body: Hiragino Mincho ProN
- Label: letter-spacing 2〜6px（間延びした余白が神秘感を演出）

---

## 画面構成

```
スプラッシュ（五芒星・回転アニメ）
  ↓
ホーム
  ├─ 今日の天命（毎朝プッシュ連動バナー）
  ├─ 晴明 or 南北 キャラ選択カード
  └─ 鑑定画面
       ├─ 悩みをテキスト入力
       ├─「式神を放つ」→ AI鑑定文生成
       └─ 詳細鑑定書（課金ペイウォール）
```

---

## キャラクター設計

### 安倍晴明（陰陽師・平安時代 921〜1005年）
- 占術: 六壬神課・陰陽道・式神
- カラー: Oracle Gold
- 口調: 文語体（〜なり、〜べし、汝、式神）
- 役割: 命式・宿命・全体運・恋愛運

### 水野南北（観相家・江戸後期 1757〜1834年）
- 占術: 観相学（人相・手相）・節食開運
- カラー: Jade Green
- 口調: 江戸口語（〜じゃ、〜なるぞ、〜であろう）
- 役割: 人相・手相・食生活・日常開運行動

---

## ビジュアル方向性
**ダークファンタジー（深海・星空・呼術符）**

- 紺色の夜空 + 星粒パーティクル
- 五芒星（晴明紋）のSVGアニメーション
- 呼術符を思わせる幾何学模様
- Co-Starの「警句的・シリアル」に近い温度感

---

## 差別化ポイント

1. **2キャラの対比** — SNSで「晴明派か南北派か」会話が生まれる
2. **呼術符UI** — 五芒星・八卦アニメで他アプリと一線を画す
3. **文語調AI文章** — 「〜なり」口調がスクショされやすい
4. **手相AIカメラ** — 南北の観相学とカメラUIの相性が抜群
5. **権利リスクゼロ** — 1000年前・190年前の人物でIP問題なし
