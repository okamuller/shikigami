# D. 追加画面設計 — 式神鑑定

## 概要
3つの主要フローのUI/UX設計。

---

## Flow 1: オンボーディング（5ステップ）

```
Step 1: ようこそ  → 世界観の提示（五芒星アニメ）
Step 2: 生年月日  → date picker 入力
Step 3: 性別     → 陰（女）/ 陽（男）の選択
Step 4: 悩み選択  → 6カテゴリのグリッド選択
Step 5: 式神決定  → 生年月日から即座に計算・演出表示
```

### 設計のポイント
- 最後の「式神決定」画面が最重要。即座に式神名を計算して見せることで「本格的だ」という信頼感を生む
- 業界水準でオンボーディング完了率50〜65%のところ、この構成で**70%超**を目標
- CTAボタンは入力完了前はグレーアウト、完了後にゴールドに変化

### 悩みカテゴリ
| ID | アイコン | ラベル | カラー |
|---|---|---|---|
| love | ♡ | 恋愛・縁 | Crimson |
| work | ⚔ | 仕事・出世 | Gold |
| money | ◎ | 金運・財 | Jade |
| health | ✦ | 健康・体 | Blue |
| family | ⬡ | 家庭・縁 | Purple |
| destiny | ☿ | 運命・天命 | Ash |

## Flow 2: 手相AIカメラ鑑定

```
Phase 1（イントロ） → 撮影のコツ説明 + 解析対象5線の案内
Phase 2（スキャン）  → カメラファインダーUI + スキャンライン演出
Phase 3（解析中）   → 五芒星スピン + プログレスバー（0→100%）
Phase 4（結果）     → 5線スコア（生命線・感情線・頭脳線・運命線・財運線）+ 南北の言葉
```

### 課金設定
- ¥480/回（都度課金）
- App Store In-App Purchase

### MVP vs 本実装
| | MVP（Phase 1） | 本実装（Phase 2） |
|---|---|---|
| 入力方法 | スライダーで手動入力 | Vision Frameworkで自動解析 |
| カメラ | UI演出のみ | 実際のカメラ起動 |
| 精度 | ユーザー主観 | 68点ランドマーク検出 |
| 開発工数 | 低 | 高 |

## Flow 3: 課金フロー（ペイウォール → プラン選択 → 完了）

```
Step 1: ペイウォール
  - 無料部分: 「あの人はあなたのことを…」前置き
  - ぼかし表示: 続きが見えそうで見えない緊張感
  - CTA: 「天命の続きを見る」ゴールドボタン

Step 2: プラン選択
  - 月額 ¥480 vs 年額 ¥3,800（「¥1,960お得」バッジ）
  - 2週間無料トライアル訴求
  - 利用規約・解約案内の明示（Apple審査対応）

Step 3: 確認画面
  - 契約内容の一覧表示
  - 「契約を結ぶ」ボタン

Step 4: 契約成立
  - 五芒星パルスアニメ + 「契約成立」の儀式感
  - 解放された機能リスト
```

### ペイウォール効果測定
| 施策 | 期待効果 |
|---|---|
| ぼかし表示 | CV率+15〜25%（見えそうで見えない緊張感） |
| 2週間無料 | 転換率+30%（Appleの推奨パターン） |
| 年額「お得」バッジ | 年額選択率+20%、LTV×1.8 |
| 課金完了の儀式感 | 解約率-10%（体験の価値付け） |

## 共通デザイン仕様

### アニメーション
| 名称 | 内容 | 使用箇所 |
|---|---|---|
| spinSlow | 20s 360度回転 | 五芒星・ローディング |
